# 🎮 PORTAFOLIO 2026 | Marcelo Aceituno

## 👨‍💻 Sobre el proyecto

Este repositorio contiene mi portafolio personal de desarrollo de software, creado como parte de mi proceso de formación como desarrollador de aplicaciones Full Stack Java.

El diseño del portafolio está inspirado en la estética de los videojuegos clásicos y las antiguas terminales de computador, utilizando una interfaz oscura, efectos visuales y elementos retro.

El objetivo es presentar de manera sencilla mis habilidades, tecnologías aprendidas, proyectos desarrollados y medios de contacto.
